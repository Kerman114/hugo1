## 笔记
### 4
#### 4.1
1.小范围判断用if-else更方便，大范围用循环
2.从左向右减数：n%最高位    从右向左减数：n/10
3.while类似于if（包括句式，以及括号内判断）
  while循环体判断条件是否为真，真则循环，假则跳出
4.在循环体内要有改变条件的机会，否则死循环
5.验证程序常用边界数据（有效范围两端的数字，特殊倍数等：个位数，10，0，负数）
6.do-while循环：先执行后判断
do
{
  循环体语句
} while（循环条件）;
(二者区别：do-while一定做一遍，while可能一次都不做)
#### 4.2
1.rand()函数：得到一个随机整数
2.a++ 和 ++a:前者 先使用，后加一；后者 先加一，后使用

### 5
#### 5.1
1.for(对于)循环：
for (初始条件;循环继续的条件;循环每轮要做的语句) {
  语句;
}
（求和初始量设0，求积设1）
2.for循环执行顺序：初始化→判断→{}内语句→每轮的动作
3.循环的选择：
 固定次数，确定的循环次数用for
 必须执行一次用do-while
 其他用while
#### 5.2
1.break:一旦遇见break，直接跳出循环
2.continue:跳过当前这一轮，直接进入下一轮循环
3.接力break：一层一层地往外break
4.goto语句：
  goto xxx;
  （直接到xxx所指的地方运行）
// 内层跳到外层的时候用就好，其他时候不要用 //
#### 5.3
1.算式中一旦有一个浮点数，其他也会变成浮点数
2.对于一次加一次减的算式求和：
  可以将加数设置为变量sign，在循环末尾加上sign=-sign
3.整数分解可以先将整数倒过来，再逆向分解（只适用于末尾没有0的数字）
4.例：五位数13425
    13425/10000=1（取首位）
    13425%10000=3425（去首位）
5.求最大公约数：枚举法和辗转相除法
 辗转相除法:
 (1)如果b=0，计算结束，a为最大公约数
 (2)否则，计算1%b=t，使得a=b，b=t
 (3) 回到第一步

### 6
#### 6.2
1.C语言的类型：
(1)整数：char，short，int，long，long long 
(2)浮点：float，double，long double
(3)逻辑：bool
(4)指针
(5)自定义类型
2.表达数的范围：char<short<int<float<double
3.在计算机内占据1-16个字节
4.sizeof：给出某个类型或者变量占据的字节数
  sizeof(int)   sizeof(a)
(sizeof是静态运算符，括号内的任何算式都不执行)
5.补码和原码可以相加得到一个溢出的0
6。整数的范围：
  char：1字节：-128~127
  short：2字节：-32768~32767
7.11111111当作纯二进制看待时时255，当作补码看待时是-1
8.unsign表示将变量用纯二进制表示，但是所表达正数的范围会扩大一倍，且不再能表达负数
9.求一个类型所能表达的最大正整数，可以依靠循环语句不断加1找出最大数与负数(或者0)的临界点
