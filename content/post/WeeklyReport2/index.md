## 笔记
**开发环境**
集成开发环境（IDE）：例如VSCode，Cursor，核心功能是文本编辑  
文本编辑器（可在终端内运行）：例如Emacs，Vim  
**Vim**  
 1.可通过键盘输入来移动光标  
 2.Vim是模态编辑器  
 3.Vim有不同的操作模式：  
    (1)Normal Mode  
    (2)Insert Mode_按I进入：插入文本  
    (3)Visual Mode_按V进入  
         Plain V mode_按Shift+V进入:选择文本片段  
         V line mode:选择整行文本  
         V block mode_按Ctrl+V进入:选择文本块  
    (4)Replace Mode_按R进入  
    (5)Command Mode:运行命令  
 4.即使不使用Vim软件本身，也可以使用其按键绑定功能  
 5.普通模式的操作  
   基础移动：h左  j下  k上  l右  
   单词：w（下一个单词）、b（单词开头）、e（单词结尾）  
   行：0（行首）、^（第一个非空白字符）、$（行尾）  
   屏幕:H:屏幕顶部  
        M:屏幕中间  
        L:屏幕底部  
   滚动：Ctrl-u（向上）、Ctrl-d（向下）  
   文件：gg（文件开头）、G（文件结尾）  
   行号：:{number}回车 或 {number}G（第 {number} 行）  
   其他：%（匹配项，例如括号或花括号）  
   查找：f{character}、t{character}、F{character}、T{character}  
        在当前行内向前/向后查找或跳到 {character}  
        使用 , / ; 在匹配之间导航  
        搜索：/{regex}，使用 n / N 在匹配之间导航

## 笔记
### 第二章
1.scanf函数里面的内容都是要用户输入的内容  
2.变量间用空格隔开（例如%d %d），则需要回车后才能输入下一个数字  
3.定义常量：const 类型 常量名=数值  
    const 是一个修饰符，意义为给变量加上一个const（不变的）的属性  
    一般对于const变量的名字全部用大写  
4.整数运算的结果只有整数，其他就是浮点数  
5.复合赋值：用五个运算符与=结合  
  例如：+= -= *= /= %=  
  （两个运算符之间不能有空格）  
6.递增减运算符：++/--  
  （对变量使用，等同于使得变量的值+/-1  a++是加1前的值,++a是+1后的值） //不好使，少用//  
7.浙大网站PAT，可用于当课练习  

### 第三章
1.判断机制：  
if (判断条件) {  
  如果条件成立的内容  
} else {  
  条件不成立的内容  
}  
2.比较运算符/关系运算：  
  '= ='相等   '!='不相等   '>'大于  
  '>='大于或等于    '<'小于   '<='小于或等于  
运算结果：成立为1，不成立为0  
3.优先级：算术运算>关系运算>赋值运算  
4.if语句的另一表达:  
if (条件)  
  判断成立执行的语句;  
else  
  判断不成立时执行的语句;  
    //用大括号更不易出错//  
5.级联条件语句：else if  
6.switch-case:  
switch (变量/控制表达式){  
  case 常量1:  
    语句1;  
    break;  
  case 常量2:  
    语句2;  
    break;  
  default:  
    语句xxx;  
    break;  
  .......  
}  
(1)case后的常量与控制表达式的值对应则执行,default在所有case不匹配时执行  
(2)若有break则直接跳出，无则向下执行  
(3)case如路牌，break如停止符号

### 系统内容  
#### 网络连接  
三种方式:  
 (1)桥接模式：虚拟系统可以和外部系统进行通讯，但容易造成IP冲突  
   （用相同的网段进行连接）  
 (2)NAT模式（网络地址转换模式）：主机和虚拟机之前可以进行连接，主机内部的虚拟机可以通过主机IP与外界连接，且不造成IP冲突，同时只能从内向外  
 (3)主机模式：独立系统，不与外界联系  
#### 目录结构  
概念：Linux中，一切都是文件  
介绍：(1)根目录下有很多个目录，每个目录都有各自的功能，是规划好的  
    (2)每个硬件都会映射到文件中  
具体内容：  
1./bin（常用）：存放常用的指令  
  地址：/usr/bin或者/usr/local/bin  
  （/sbin：类似usr，s为super user）  
2./home（常用）：存放普通用户的主命令，每个用户都有一个自己的目录  
3./root（常用）：系统管理员目录，超级权限者用户主目录  
4./lib：动态连接共享库，大部分应用程序都要用到这些共享库  
5./lost+found：存放非正常关机情况下的一些文件  
6.etc（常用）：系统管理所需要的配置文件和子目录（类似于数据库？）  
7./usr（常用）：用户的应用程序和文件存放的目录，类似win的progtam files  
8./boot（常用）：使用/启动Linux时的一些核心文件（别乱动）  
9./proc 内存的映射文件（别乱动）  
10./srv 存放启动后需要提取的一些数据（别乱动）  
11./sys 系统文件（别乱动）  
12./tmp 存放临时文件  
13./dev 类似于设备管理器，用文件的方式存储硬件信息  
14./media（常用） 识别到设备映射文件的文件存放地（例如U盘等）  
15./mnt（常用）临时挂载别的文件系统，可将外部存储挂载在/mnt/上  
16./opt 给主机额外安装软件所摆放的目录，默认空  
17./usr/local（常用） 给主机安装软件的另一个目录  
18./var 存放不断被扩充，常被修改的目录  
19./selinux(security-enhanced linux)  
   安全子系统
