## 笔记

### CSS(Cascading Style Sheets)
层叠样式表，用于定义各个元素的样式  

### CSS语法：
选择器 {    
    属性1:属性值1;  
    属性2:属性值2;  
}   
(1)选择器声明可以写无数条属性   
(2)属性以分号结尾   
(3)以属性对的结构出现   

1.内部样式表：把CSS样式放在<head></head>标签对中    
<style> 
  选择器 {  
    属性1:属性值1;  
    属性2:属性值2;  
}   
</style>    

2.CSS的导入方式：   
(1)内联样式：直接在标签里用<style></style>标签  
(2)内部样式表   
(3)外部样式表：用于多个网页中运用相同样式，需要另创文件需要用<link>标签导入     
导入优先级(1)>(2)>(3)   

3.选择器：用于选择要应用样式的HTML元素  
类型：  
(1)元素选择器：选择器直接用需要样式的元素标签名 
(2)类选择器：选择器用标签的类名（给标签定类：  class:"类名"  属性） 
(3)ID选择器：选择器用标签ID命名（给标签ID：  id="id名"  属性）  
(4)通用选择器：给所有元素使用，选择器前加上 * 号    
(5)子元素选择器：   
.父元素 > .子元素 { 
  ......    
}   
(6)后代选择器： 
.父元素 后代标签 {  
  .......   
}   
(7)相邻元素选择器： 
元素 + 相邻元素 {   
  ......    
}   
(只会选择同一级别元素下紧跟其后的第一个标签)    
(8)伪类选择器： 
#元素id(或者标签):hover {   
  ......    
}   
（交互时出现的形式）    
(9)伪元素选择器：   
::before(或者after等) { 
  ......    
}   

4.复合属性：style="font:属性值1 属性值2 属性值3;"   

### 盒子模型    
属性（均是复合属性，可以用一个属性设置多个样式）：  
(1)内容（Content）：盒子包含的实际内容  
(2)内边距（Padding）：围绕在内容的内部，内容于边框之间的空间    
(3)边框（Border）：围绕在内边距的外部，是盒子的边界 
(4)外边距（Margin）：围绕在边框的外部，是盒子与其他元素的空间   

#### 浮动   
（float:left/right/....也是一种属性）   
1.网页布局五种方式：标准流 浮动 定位   "Flexbox"/"Grid"（自适应布局）   
2.应用：让同一个块级元素在同一行内排列显示，浮动的元素贴在一起  
3.浮动相对于父元素进行浮动  
4.三大特性：    
(1)脱标：脱离标准流 
(2)一行显示，顶部对齐   
(3)添加浮动的元素具有inline-block的属性 
5.清除浮动：添加属性overflow:hidden 

#### 定位   
（position:）   
1.定位方式  
(1)相对定位(position:relative)：相对于元素的位置进行定位，不脱离文档流（表面位置改变，实际位置没变）     
(2)绝对定位(position:absolute)：相对于已经定位的祖先元素进行定位        
(3)固定定位(position:fixed)：就是固定不动的定位，不随滚动进行定位（网站小广告）

## 笔记
### JavaScript
概念：是一种轻量级、解释级、面向对象的脚本语言，主要被设计用于在网页上实现动态效果，增加用户与网页的交互性  
用处：使得网页不再是静态的，可以依照用户的操作而变化    

#### 作用
1.客户端脚本：在用户浏览器中执行，实现动态效果和用户交互    
2.网页开发：与HTML和CSS协同工作，使得网页更有交互性和动态性 
3.后端开发：通过Node.Js，JS也可以在服务器端运行，实现服务端应用的开发
